Commentaire

Connecter un dashboard

Pour un site que vous contrôlez : copiez ce script dans son HTML, avant </body>, puis rechargez son URL dans HtmlSift. Le site doit autoriser son affichage en iframe et ce script via sa politique CSP.

Le connecteur transmet les textes et dimensions des éléments au parent HtmlSift et neutralise les liens http/https dans l’iframe. Ne l’installez que dans une copie dédiée à l’audit. Les restrictions X-Frame-Options / frame-ancestors ne peuvent pas être contournées par ce fichier.

Autre possibilité : importez un fichier HTML. Les scripts sont exécutés dans un aperçu isolé. Les ressources relatives nécessitent une URL de base valide dans votre HTML ; les fichiers voisins ne sont pas importés automatiquement.
